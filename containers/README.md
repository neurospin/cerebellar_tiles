# Container folder

The folder contains the logic for the different containers used to process MRIs. You need to install all the required `sif` files before running
this pipeline. 

<span style="color : red"> All the containers need to be `sif` files to be able to be used on HCP such as Jean-zay or TGCC<\span>

## Current containers needed

### Acapulco

This is the cerebellum segmentation tool. It can be installed by following [this link](https://gitlab.com/shuohan/acapulco).

The version used for this pipeline is the CPU version that is used for inference.
